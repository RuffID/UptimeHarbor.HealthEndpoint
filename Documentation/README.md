## Как читать

Согласованные требования обязательны для будущей реализации. Подтверждённый контракт потребителя получен чтением исходников соседнего UptimeHarbor на 2026-11-01. Предлагаемая архитектура ещё не реализована и может уточняться в пределах согласованных требований. Открытых вопросов сейчас нет; список сохраняется для последующей работы. Готовность документов не означает начала реализации.

Документы подключены к `.slnx` как solution items и не копируются в проект библиотеки. Наличие документа или этапа не подтверждает выполнение описанной функции или проверки.

# Первичная реализация UptimeHarbor.HealthEndpoint

Дата создания: 2026-11-01. Общий статус реализации: `completed`.

## Основание, цель и текущее состояние

Основание — поручение подготовить независимую библиотеку для HTTP-контракта мониторинга UptimeHarbor. Согласованные требования находятся в [ТЗ](../../Business%20logic/Business%20requirements.md), фактический контракт потребителя — в [архитектуре](../../Technical%20documentation/Architecture.md#consumer-contract).

Этапы 01–05 завершены в согласованном объёме. Реализованы настройки, снимок процесса, Add/Map и анонимный GET с отдельным JSON и запретом кеша; подготовлена Release DLL 0.0.1 и инструкция прямого подключения. Этап 04 принят пользователем по ответу CostVision.Web и стабильности времени при обновлении страницы. Его DLL-ссылка и копирование в output дополнительно подтверждены чтением фактических файлов в этапе 05. Финальные сборки без ошибок и предупреждений, 93 изолированных теста успешны. Samples и отдельного проверочного потребителя нет. Содержание исторических этапов 01–04 сохранено, ограничения внешних проверок не расширяют подтверждённую матрицу.

Цель — подключаемый к существующему pipeline анонимный endpoint с точными именами JSON-полей и фактическим временем запуска процесса. Библиотека не владеет listener, портами, Kestrel, TLS, nginx, firewall, Docker и БД. Независимость production-библиотеки от проектов UptimeHarbor обязательна; исходный репозиторий используется только для чтения и тестовой компиляции checker.

Согласованный объём: минимум .NET 10 / ASP.NET Core 10, без поддержки 8 и 9; поставка DLL прямой ссылкой из libs без NuGet и ProjectReference; автоматическое имя обрезается до 256, явное после Trim допускает 3–256 и иначе вызывает исключение при запуске. Endpoint подтверждает только способность приложения отвечать и использует отдельные настройки JSON. Конфликты маршрутов и повторное подключение библиотека не обнаруживает; разработчик обеспечивает свободный Path и один вызов Add до одного Map. Проверка синтаксиса Path при старте сохраняется.

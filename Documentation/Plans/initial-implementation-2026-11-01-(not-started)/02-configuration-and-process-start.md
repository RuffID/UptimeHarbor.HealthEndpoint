# 02. Реализовать настройки и снимок процесса

Статус: `not-started`.

## Цель

Реализовать стартовую валидацию настроек и неизменяемый снимок имени приложения и времени запуска текущего процесса.

## Зависимости

[Этап 01 — технический контракт](01-technical-contract.md).

## Работы

Создать options и `IServiceCollection`-расширение; после Trim проверять явный Name на 3–256, автоматически полученный ApplicationName при превышении 256 обрезать с сохранением корректного Unicode. Не читать `.csproj`. Валидировать Name/Path при запуске; не генерировать замену пустому имени. Один раз получить фактический старт текущего процесса, нормализовать UTC и сохранить неизменяемый снимок до обработки запросов. Не заменять недостоверный источник текущим временем. Создать содержательный локальный `AGENTS.md` при появлении собственного кода.

## Затрагиваемые части

Проект библиотеки, его локальные инструкции, документация конфигурации и жизненного цикла. Тестовую инфраструктуру добавлять только в разрешённом объёме будущей реализации.

## Проверки

Границы явного имени 2/3/255/256/257 после Trim, допустимость 200, пустая строка, кириллица и внутренние пробелы без дополнительных запретов; автоматические имена длиной 1/2/256/257, обрезка длинного имени, пустое автоматическое значение, корректность Unicode на границе. Проверить ошибочные и допустимые пути. Убедиться, что ошибка настройки возникает при старте без первого запроса. Проверить освобождение временного Process и отсутствие fallback. Диагностика на английском, без дампа options/секретов и ложного сообщения об успешном запуске.

## Критерии приёмки

Минимальная и явная регистрация работают по утверждённому API; невалидные настройки останавливают запуск; снимок времени соответствует процессу и не изменяется при обращениях. Нужные compile-check и изолированные тесты выполняются лишь после разрешения.

## Результат

Работы этапа не начаты, результат отсутствует. Создан только документ этапа; реализация, сборка и проверки выполнения этапа не проводились.
